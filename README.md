# Kino XII

Cinema-ticketing single-page application built for the Redberry Bootcamp XII assignment.

## Technology

- HTML5
- CSS3
- Vanilla JavaScript
- ES Modules
- Native browser APIs
- Fetch API

## Documentation

Project specifications and architecture documentation are stored in the [`docs`](./docs) directory.

## Development

Local development uses the VS Code Live Server extension.

Implementation is developed incrementally according to the project specifications and architecture.
